# Meme mirror

Real-time CV plugin that watches your camera, detects your emotion/pose,
and retrieves the most similar meme via multimodal embeddings.

<!-- GIF / видео позже -->

## How it works

Camera → Face/emotion detection (MediaPipe) → CLIP embedding →
FAISS similarity search → Top-K memes

## Stack

`Python · MediaPipe · CLIP · FAISS · FastAPI · OpenCV`
